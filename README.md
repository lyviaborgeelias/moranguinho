# Segredos de Tutti-Frutti

Projeto organizado no mesmo padrão full stack do Filminis Django: frontend React/Vite e backend Django REST.

## Frontend

```bash
cd frontend
npm install
npm run dev
```

## Backend

```bash
cd backend
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
python manage.py migrate
python manage.py runserver
```
